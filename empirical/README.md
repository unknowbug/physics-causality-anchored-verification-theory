## 「实证」与「应用」的区别

应用是拿框架去分析一个对象；实证是**框架本身被现实检验的一次记录**——**包括检验失败的部分**。

所以这一栏里有一篇的结论对这套理论是不利的：《投稿被拒的反身性案例》记录的是它被学术期刊系统性拒绝。这篇留着，不是因为它证明了理论，是因为它**检验了理论的处境**——而且它自己的分析给出一个不好看的解释：学术期刊的 B2 还按印刷时代的稀缺性运转，而这个理论的 B1 与它不可通约。

**把对自己不利的证据摆在最显眼的地方**，是这套发布规则里唯一一条不写进 `PUBLICATION.md` 的规矩。
