## 关于「禁止引用」与「发布」

两者是**正交**的：禁止引用约束的是「能不能当证据」，不约束「能不能被看见」。所以社会力学那 8 篇自标「禁止引用」的笔记，正文一字未改、只加检验标注，发布在 `猜想/`。
