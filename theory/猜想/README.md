## 一、这个目录是什么，不是什么

**是：** 一批**暂定猜想**。它们有主张、有推理、有可以被攻击的结构，但都还没过第一律要求的检验。

**不是：**
- 不是本理论的一部分。判据以 `../core/唯物实践论：纪律与公理 第六版.md` 为准；
- 不是可以引用的证据。任何引用此目录内容的论证，都不构成对该内容的证明；
- 不是"早期草稿"——草稿是过程，猜想是主张。过程性的东西（推演记录、变更账、否决路径）**不在本目录**，也不在本仓库。

## 二、为什么发

按第二律（框架必须包含其自身被证伪的可操作路径）：这批东西如果只躺在私有库里，能被证伪的路径只有作者自己想得到的那一条。**公开是被证伪的前提，不是被承认的前提。**

所以这里发布的是**待证伪的主张**，不是结论。

## 三、标注怎么读

每篇头部有一个「B2 定义检验标注」，全文状态四取一：

| 标注 | 含义 | 强度 |
|---|---|---|
| **与正典相容** | 与《革命论》§2.1–§2.2 的 B2 定义（P1/P2/P3）无矛盾，且有实例或结构对应 | 逻辑一致 ＋ 个案支持。**不是证明** |
| **部分冲突** | 某条具体映射与 P1–P3 矛盾 | 内部矛盾，非实验推翻 |
| **需重述** | 不矛盾，但表述会把读者引向与正典相反的读法 | 措辞级 |
| **未对撞** | 没有检查过 | **零信息** |

**检验基准：** 《革命论》§2.1–§2.2（2026-10-30 按 Q-0010 裁定入正典）

- **P3** B2 不给 A 层下令，只改行为路径的物理成本

## 五、标注本身可被推翻

按第三律，规则必须包含其自身被挑战的路径——**标注也是规则**。

每篇标注末尾写明「推翻方式」。例如：

> 若 P2 放宽为「B2 可提供恢复力」，则「k 位冲突」判定失效。

**若你认为某条标注标错了，直接指出依据即可——标注不是裁定，它是 2026-11-07 这一次对撞的记录。**

## 六、最值得读的一处

不是那两篇「相容」的，是那篇**「部分冲突」**的。

`力学概念映射推演` 里 `k = f(B2 的制度刚性 × …)` 这一条，决定了「改革回潮」到底是**物理律**（自然回弹、无人负责）还是**人的编排**（有人抬高了改革路径的阻力、可归因）。

同一现象，两种读法给出相反的责任结构。这个分歧没有裁定，不是忘了裁，是**它本来就该由读者看见**。
