## 摘要

中文作为携带性符号系统（符号形体部分保留所指的可观测特征，[2]§5.1），其字面可理解性既是结构性优点，也是结构性风险来源：字面拼接制造"已经理解"的安全错觉，使用者带着错误模型继续使用而不触发警报，且该错觉在现象学上与真实理解不可区分。本文以三项词汇自测呈现中文词失配形态的完整版图——假懂（成语望文生义）、半懂（唯物不足型）、不懂（音译词"鲁棒性"失锚型；规范写法为"健壮性"）——并论证：中文式语义偷渡（物理残余硬拼）与拼音语言式语义偷渡（无锚互印、自指悖反）是两种不同机制，分别由第一律（锚定检验）与自指一致性（Δ 审查）两种判据裁决；两种问题不是同一种错误的两面，而是同一自洽性要求（声称与基准的匹配）在两种系统本质下由两种判据分别裁决。论文最后指出方法论自身的自指风险：其术语与自检工具与病灶同源，对方法论整体而言，唯一的外部校准是跨语言对照，而等价翻译已被证明不可能——方法论因此处于结构性状态：内部自检永远不够（§5.2 本文推论），外部校准永远可能但永不等价，其正当状态只能是"我尚未被推翻"。

**关键词**：携带性符号系统；假理解入口；语义偷渡；判据分工；第一律；自指一致性

# 第一部分 中文的假理解入口

## 1.1 三项词汇自测与失配形态

本节给出三项词汇自测。读者可先行写下各自对下列词汇的理解，再对照各小节给出的词典义（规范义）——对照完成的瞬间，即完成对"安全的错误"的第一次观测。

### 1.1.1 成语自测：假懂（冲突型）

下列五个成语中，字面拼合给出的理解与词典义相反或严重偏离：

| 词    | 字面拼合（可拼出的通行理解） | 词典义（规范义）           | 误读来源子类 |
| ---- | -------------- | ------------------ | ------ |
| 差强人意 | 差劲，不令人满意       | 大体上还能让人满意（差＝稍微）    | 反向     |
| 不刊之论 | 不能刊登的言论        | 不可更改、不可磨灭的言论（刊＝删改） | 反向     |
| 文不加点 | 写文章不加标点        | 文章一气呵成，无须涂改（点＝涂改）  | 反向     |
| 屡试不爽 | 屡次尝试都不顺利       | 屡次试验均无差错（爽＝差错）     | 错训     |
| 炙手可热 | 烫手，抢手          | 手一挨近就感灼热，比喻权势气焰很盛  | 偏离     |

注："七月流火"因[11]已收录"现也用来形容天气炎热"义项，不列入冲突型自测表；其机制与规约化吸收分析见 §1.2.3。

以主例"差强人意"说明：字面拼合取"差"之今义（差劲），得"很不令人满意"；词典义取"差"之古义（稍微），为"大体上还能让人满意"。误用者以错误模型表达时，其表达的意思与听者接收的意思完全相反，而双方都可能毫无察觉——错误模型不触发任何警报。

本节将"冲突型"定义为：字面义 L 与词典义 D 相反或严重偏离（含单字错训）。

### 1.1.2 简单形式化声明

假理解入口：字面可理解性超出真实语义支撑（本节以词典义为真实语义的公开基准）的部分。本文其余形式化装置自第四部分起引入。

### 1.1.3 唯物自测与双形态：半懂（不足型）

问："唯物"是什么意思？通行回答指向字面义"只有物"的操作态度——相信实在的东西、不搞虚的。再问：在"唯物主义"语境下讨论时，该词必须携带什么？答案指向唯物本体论陈述（世界本质是物质）——该层不能由字面组合推出，只能来自哲学史的框架染色（[3]0.2、[3]0.3）。

这一对照暴露了与成语不同的落差类型：字面义本身是正确的（"唯物"确实表达实在态度），但字面义不足以支撑理论语境的完整负载——字面义 L 是语境负载 D 的真子集（L ⊂ D）。使用者以字面义进入理论语境，不知道"必须携带"本体论陈述这一要求，讨论在错位基础上进行而不自知。因为字面义是对的，这一形态比成语更不触发警报。

（记号约定：D 在冲突型中指词典义，在不足型中指理论语境的完整负载；两者的统一形式化见 §4.1.2。）

同一词存在两种使用形态：**索引使用**（字面义作索引，残余不等于定义——唯物实践论以术语总判决声明采用字面义、不接受本体论偷渡，[3]0.3）与**实体化使用**（字面义被固化当作定义本身——仅凭"唯物"两字进行马克思主义导论，不知道语境要求额外负载）。两者的判别是描述性的：词义使用是否与锚定支撑匹配（第一律：词义使用与锚定支撑匹配的可检验性判据，系统层面见《[1]》），不涉及价值评价。

本文三组术语在此首次出现，层级关系如下（完整形式化见 §4.1.6）：

| 层级 | 术语对 | 回答的问题 |
|---|---|---|
| 使用层 | 索引使用／实体化使用 | 使用者如何对待字面拼合产物 |
| 判据层 | 匹配态／失配态 | 声称与锚定是否匹配 |
| 框架层 | 锚定使用／异化使用 | 词义负载是否脱离 A 层锚定 |

纵向投影：索引使用 → 匹配态 → 锚定使用；实体化使用 → 失配态 → 异化使用。

【脚注：本文"实体化使用"与[3]所称"实体化预设"（Being 的语法名词化预设）不同义；本文用法是第五版「异化 = 脱离 A 层锚定」在词汇使用层的投射，以方法论定义为准。】

回答情况为小范围观察，未获样本支持前，本文不作发生率断言。

### 1.1.4 健壮性自测：不懂（失锚型）

问："鲁棒性"是什么意思？读者仅凭"鲁"与"棒"二字，无法推得任何与"抗干扰、稳健"相关的语义线索——字面拼合在此完全失效。再展示"健壮性"：健＝健康，壮＝强壮，读者可推得"健康强壮、耐受扰动"的方向。同一个外来词（robustness），音译构词与意译构词的差别，在第一律判据下一次裁决。

"鲁棒性"的失锚在于：作为音译构词，其符号形体不携带任何与所指相关的 A 层残余（A 层残余：符号形体在生成过程中保留的所指可观测特征，[2]§5.1），词义完全依赖外部约定（英文 robustness 与学术圈的习用）。它冒充携带性中文词进入学术术语层，使用者被迫使用却无法从词本身获得理解——违反中文词的第一律条件：词义必须在符号系统内可锚定。

本文中"鲁棒性"仅以加引号的被诊断对象身份出现；作者操作性语言一律采用"健壮性"——该术语总判决（2026-08-12）已执行，本文写作即执行该判决。

### 1.1.5 三种失配形态：完整版图

| 形态  | 例     | 字面义 L 与词典义 D 的关系 | 体验  | 警报缺失原因    |
| --- | ----- | ---------------- | --- | --------- |
| 冲突型 | 成语    | L 与 D 相反或严重偏离    | 假懂  | 字面可拼，免除查证 |
| 不足型 | 唯物    | L ⊂ D，被当作 L ＝ D  | 半懂  | 字面正确，免除补全 |
| 失锚型 | "鲁棒性" | L 不存在            | 不懂  | 无物可查，无从怀疑 |
|     |       |                  |     |           |

三种形态的共同点：警报不触发。区别在于警报缺失的原因。该版图构成中文词失配形态的完整分类；完备性论证见 §1.2。

需要限定：本文三格形态学针对保有 A 层残余的中文词主流；中文中也存在理论义近乎无锚的抽象词（如"道德""正义""好/坏"等——其字形残余不足以独立支撑理论义项，故在理论使用中按无锚处理），其判据按命题 4.6 转入 Δ 域，属于本文形态学的边界情形。

这一入口首先欺骗的对象是使用者自身；就本文主题而言，先于读者的是作者（方法论自身），§5.1 展开。

## 1.2 望文生义作为安全的错误

### 1.2.1 机制：先于反思的自动误认

"不知不知性"（[3]5.2.3）常被直观地理解为递归反思：读者读词、理解字面、发现自己正在误解。这一描述是后发的、自觉的，因此是表面的。真正的机制先于反思：字面拼接在理解发生之前就已给出"可以理解"的入口，使用者带着错误模型继续使用，全程不触发警报。普通反思不是可靠的检测手段，而是事后解释；例外是具备执行结构的功能词（§6.1.1），其诊断由词形强制执行，不依赖反思。

四步机制如下：

一、类比通道。字面可拼——"流火"拼作"流动的火"，再推出"热"，拼合成功，因此不查证。字面可理解性成为可以不查证的理由。

二、固化。误用义随媒体与日常传播成为主流用法（用例观察，不作发生率断言）。

三、实体化。主流误用义被新学习者当作规范义学习——错误模型获得传承。

四、安全的错误。使用者带错误模型表达与理解，零警报；直到外部校准（词典核对或他人纠正）才暴露。

### 1.2.2 三种失锚形态学

失配形态的三分类与 §1.1 自测对应：

冲突型（成语）：字面义 L 与词典义 D 相反或严重偏离——字面是陷阱——假懂。

不足型（唯物）：L 真实但不足（L ⊂ D）——字面义正确，故更隐蔽——半懂。

失锚型（音译词）：L 不存在——词义完全依赖外部——不懂。

### 1.2.3 成语：无外来者参与的偷渡——时间上的偷渡

成语误读不需要外来语义参与，其机制是中文内部的时间过程，分三层：

主机制：语素义历时错位。成语冻结造词时保留了字素的古义（差＝稍微、刊＝削改、爽＝差错、点＝涂改）；今日读者以字素的今义重新拼合，拼合模型与词典义冲突。偷渡者不是外来语义，而是语素义在时间轴上的漂移——纯中文内生，无外来者参与。[2]§5.3 的引申义链条（本→根→本源→本体论）显示字素义沿时间轴漂移；成语正是字面义不稳定的场域。

辅助来源一：文化指涉丢失。"七月流火"中"火"指大火星（心宿二）、"流"指西沉，依赖古代天文知识；错位来源是专门指涉而非普通语素义。其误读义"天气炎热"因使用普遍，已被[11]吸收为"现也用来形容天气炎热"——故它不再进入 §1.1.1 自测表，而并入下文的边界排除。

辅助来源二：域转移误读。"炙手可热"的比喻目标域从"气焰、权势"被移作"热门、抢手"，无时间因素，与主机制并列但性质不同；该误读义未获词典收录，仍属当前误用。

边界排除：规约化吸收。部分误读义已被词典收录为规范义——如"空穴来风"的"无根据"义项与"七月流火"的"天气炎热"义项——不再是错误，因为第一律的基准即当前词典义本身，基准已移动。本文只诊断相对于当前规范锚点的失配，不把已规约化的义项当作误用。

### 1.2.4 现象学不可区分性

假理解与真理解在现象学上不可区分：两者都"懂了"，都不触发警报。中文内部的观测因此失效——读者无法从自身内部判断自己是否处于假理解状态。这是中文内部自检的结构性盲区，也是 §5.1 方法论自指风险的微观基础。

### 1.2.5 结论：内生结构性倾向

望文生义是携带性系统的内生结构性倾向：纯中文固有词都无法阻止它（成语自证），因此它必然成为外来语义偷渡滥用的基础设施——外来框架染色利用"字面可拼所以不查证"的通道，将自身负载灌入中文词。这一结论把第一部分（第一律判据域）与第三部分（两种偷渡对比）连接起来。

# 第二部分 西哲词汇的偷渡

## 2.1 西哲的语义偷渡

第一部分表明，中文词的失配形态为外来语义偷渡提供了滥用通道。这一节转向偷渡的另一来源——拼音语言系统自身。为使本节自足，以下内容转述[4]与[2]的相关论证，读者无需回溯对位专著。

### 2.1.1 词义的来源：无锚与使用史

拼音文字的符号形体不携带 A 层残余：词形与词义的关系是纯粹约定（[2]§5.1）。字母的组合不提供任何关于所指的线索——"water"与水的联系不来自字形，而来自约定。这意味着拼音词义没有可资检验的公开锚点：词义无法被第三主体在符号系统内部核对（论证见 §4.1.3 引理 4.4）。

于是词义只能来自一个来源：使用史。本文按[3]0.2 的框架染色机制，采用如下工作定义（非全称语言学断言）：一个词的意义，是其在整个理论传统中被使用的历史的总和。理论传统的框架染色由此进入词义——词义不再是"事物本身的索引"，而是"框架主张的沉淀"。这是拼音语言词义的结构性特征，不是个别译者的疏忽。

### 2.1.2 声称的四层构造：从"我完备"到"最终真理"

[4]将"关于自身的声称"的异化展开为四层结构。设一个声称体系由公设、推导、结论与防御构成，四层结构是"我完备、我一致、我的结论是最终真理"这一声称的四步构造：

**L1 免检（公设层）：** 体系将核心声称设为不许检验的公理——需要检验变为不许检验，第一次免检完成。公设的姿态是："这是出发点，不接受质疑。"

**L2 增殖（推导层）：** 在免检公设之上进行推导。推导在体系内部自洽运行，但公设未锚定，推导是逻辑空转——声称未锚定，却以精密的形式出现。

**L3 借信（B1→B2 偷渡，结论层）：** 推导层的严密性被整体转移到结论上，结论被呈现为"已被证明"的定理姿态。推导的数学自洽被直接断言为对现实世界的结论——体系内自洽不等于体系外有效。母范畴错误在形式化领域精确执行。

**L4 免疫（防御层）：** 为结论配置避险条款——"条件不满足""尚未达到均衡""这是特例"——任何反例都被条款吸收，修正通道被堵死。B1（认知框架）与 B2（协调规则）互指完备（B1/B2 为方法论三层六子类术语，见[3]第三篇），体系对反例免疫。

四层共同构造完备性宣称：L1 豁免检验、L2 增殖未锚定的推导、L3 将内部自洽偷渡为外部结论、L4 免疫一切反例。完备性宣称是唯一在结构上直接越界的操作，也是整个结构闭合的开关。

异化系统（L1–L4）拒绝 A 层锚定，构成 B 层闭合系统；其自指一致性检查无法通过外部锚定完成，必然违反公理 6。公理 6（Δ 自指一致性，[3]）：任一 B 层符号结构，其关于自身的声称必须自洽（不携带未声明的预设）。健康系统（开放）通过 Δ 审查——开放与封闭的差异即锚定与否（[4]§1.4、§3.6–3.7）。

### 2.1.3 一个完整的四层案例

以自由主义经济学的"市场有效"声称为例（[4]§4.1，转述）：

L1 公设层：理性经济人、完全信息、效用最大化——三者均不可独立检验（行为经济学实验表明系统性偏离，完全信息是反事实理想化）。

L2 推导层：阿罗—德布鲁一般均衡存在性定理、动态随机一般均衡——数学推导确实严密，公设内完全自洽。

L3 结论层："数学证明了市场有效"——L2 的数学自洽被直接断言为对市场有效性的证明。

L4 防御层："市场不完善""尚未达到均衡""模型需要加金融摩擦"——反例被避险条款吸收。二〇〇八年金融危机本是 A 层冲击穿透四层壳的契机，结果被"加金融摩擦"吸收，公设层纹丝不动。

Δ 审判：提取核心声称"市场有效已被证明"与核心术语"有效""证明"——"证明"携带"形式系统可完备裁决真理性"的预设——该预设被哥德尔不完备定理否决：声称在表述完成的瞬间已经自我违反。

### 2.1.4 偷渡机制：无锚互证与假装外部参照

将四层构造还原到词义层面，即得西哲偷渡的机制链：词义无字形锚（§2.1.1）→ 词义是框架染色的沉淀 → 框架在系统内部互相印证（词义由框架定义，框架由词义支撑）→ 系统以内部宣称维持地位（"我定义了它，所以它就是这个意思"）→ 进一步宣称结论普遍有效、框架完备——即假装指向外部世界，假装完备。

与第一部分对照：中文靠物理残余硬拼（残余是真实的，被固化滥用）；拼音语言靠无锚互证（无残余，靠内部互证撑起声称）。两种机制的差别将在 §3.1 系统展开。

### 2.1.5 三个案例的统一结构

为便于对照，以下三个案例（Being、"唯物"、女权）按统一结构展开：**词义来源——负载——机制——结果——判据指向**。三个案例分别覆盖无锚系统词义塑造的三种路径：语法、翻译、使用史。

### 2.1.6 案例一：Being——语法预设

**词义来源：** 希腊语的语法结构——系词"εἰμί"同时承担语法指称与存在论承诺。

**负载：** "存在是可以被名词化的属性"——"实体"（οὐσία）是"是/存在"的名词化。

**机制：** 语法预设。"X is"的语法结构本身已预先完成"存在"的断言；语言的形态学在批评者写下第一个术语之前，已经替哲学做了决定（[2]§3.1）。

**结果：** 亚里士多德以被语法决定的语言追问"存在之为存在"，预设先行、全程不触发警报——他自我违反了一个从未声明过、但被他的语言强制执行的条件。

**判据指向：** 无锚系统的词义被语法塑造——声称与符号负载不匹配，属于 Δ 判据域（自指一致性审查）。

### 2.1.7 案例二："唯物"——翻译负载转移

**词义来源：** 中文约定（字面义"只有物"）与 materialism 框架染色的叠加。

**负载：** 唯物本体论陈述（世界本质是物质）。

**机制：** 翻译选择。materialism 译为"唯物"时，译者面对字面义（"只有物"的实在态度）与框架义（本体论断言）的选择；绝大多数翻译实践默认取框架义——译者自身生活在框架染色的传统中，无法察觉字面义与框架义的差别（[3]0.2）。本体论断言经翻译进入中文词的默认理解。

**结果：** 中文使用者以为"唯物"表达"相信实在、不搞虚的"，实际接收的是"世界本质是物质"的本体论陈述——与第一部分 §1.1.3 的唯物自测互为镜像：§1.1.3 是中文侧观察到的形态（字面义真实但不足，半懂），本案例是西哲侧发生的机制（框架染色经翻译灌入，偷渡完成）。

**判据指向：** 偷渡来源在西哲侧（框架染色），落点在中国侧（中文词锚定失配）——落点侧的检验由第一律裁决。

### 2.1.8 案例三：feminism——使用史悖反

本案例以拼音语言词汇 feminism 为对象。其语义问题完全来自英文的使用史，不涉及中文构词（"女权"的字面拼合并不产生误导）——污染发生在无锚系统自身。术语依据[5]§2.4，源文使用中文术语；英文对应词为本文标注。

**词义来源：** 使用史——不同时期女权主义主张的总和。

**负载：** 互相冲突的主张。

早期——suffrage（选举权）：法律条目的增删，有明确的实施方案与到期时限，认知信用极高。

中期——equal pay for equal work（同工同酬）：可量化的制度目标，信用尚在——但同工验证在此阶段已被规避操作（[5]§2.4）。

近期——patriarchy（父权）、male gaze（凝视）、objectification（物化）、microaggression（微侵犯）、"你说话的姿态本身就是暴力"（your tone itself is violence）：不可检验的认知主张，认知信用加速贬值（同上）。

**机制：** 使用史沉淀无清理。同一词汇在不同时期承载的主张，检验性逐期崩塌，各期主张互相冲突，却全部沉淀在 feminism 这一个词中。

这一时序显示无锚系统内的动态：早期具体诉求（选举权、同工同酬）尚可经 Δ 兼容（可检验、可修正）；后期不可检验主张沉淀后逐渐违反 Δ。异化不是语言类型的一次性判定，而是词义负载在使用史中缺乏 A 层锚定后的过程性结果。

**结果：** 语义悖反——同一词下，可检验的具体诉求（选举权）与不可检验的泛化主张（微侵犯、"你说话的姿态本身就是暴力"）并存且互斥；源文观察：支持者自身开始无法区分实际的被剥夺与词语膨胀出来的压迫体验。词义的自相矛盾不触发任何警报。在当代英文使用中（本文观察，不作发生率断言），feminism 一词同时指称争取投票权的运动与"你的语气本身就是暴力"的指控——两个主张互斥，共享同一个词，而共享机制对使用者不可见。

**判据指向：** 无锚系统的词义等于使用史总和——主张冲突即词义不自洽，属于 Δ 判据域。

### 2.1.9 定位声明

西哲侧的语义偷渡是[4]已充分论证的领域（Δ 判据域）。本文的贡献不在重述该论证，而在两点：与第一部分的机制对照（§3.1），以及判据分工定理（§4.1）——后者说明为何西哲侧的问题只能由 Δ 裁决，而中文侧的问题由第一律裁决。

# 第三部分 两种偷渡的对比

## 3.1 对比：物理残余硬拼与无锚互印自指悖反

第一部分与第二部分分别展示了中文侧与西哲侧的偷渡形态。本节将两者并置，给出系统对比，为第四部分的判据分工定理提供现象基础。

### 3.1.1 中文偷渡：物理残余硬拼

中文词的偷渡建立在真实的字形残余之上。"河"字带"氵"旁——字形真的指向水类（[2]§5.1）。残余是真实的锚。偷渡发生在残余被滥用之时："指向水"被当成"已经理解河的一切"——残余从锚变成假理解入口。

第一部分的三项自测展示了这条路径的三种形态：成语的类比通道（字面可拼所以不查证）、唯物的不足型（字面正确所以不补全）、音译词的失锚型（无物可查所以无从怀疑）。共同点是：残余——或残余的缺失——被当作理解完成的证据。

### 3.1.2 西哲偷渡：无锚互印与自指悖反

西哲词的偷渡建立在无锚之上。符号没有字形残余——词义只能来自使用史，即框架染色。框架染色在系统内部互相印证：词义由框架定义，框架由词义支撑；系统以内部宣称维持地位，进而假装指向外部世界、假装完备（§2.1.4）。

第二部分的三个案例展示了词义塑造的三条路径：语法（Being）、翻译（"唯物"）、使用史（feminism）——塑造过程全部在主体察觉之前完成。

方法论的"迫不得已"是结构性的，不是设计选择：两种偷渡的机制不同、判据不同、防线不同——方法论必须同时维护两套不同方向的约束机制。诚实性纪律（术语总判决）约束中文侧的实体化使用；自指一致性审查（Δ、哥德尔映射）约束西哲侧的封闭宣称。没有单一检验标准能同时覆盖两者——这一事实在第四部分获得形式化表述（判据分工定理）。

# 第四部分 判据分工

## 4.1 判据分工定理

第一部分与第二部分给出现象，第三部分给出对比。本节将前述现象收束为一个形式化定理：系统的本质属性决定其诊断判据。本节的全部形式化装置按[3]6.4 纪律区分两类陈述：引用既有定理的数学/逻辑内核，与本文所作的接口论证（理论映射）。

### 4.1.1 统一原则：自洽性要求

两种偷渡看似无关（物理残余硬拼与无锚互印），但共享同一个形式结构：**声称与基准的匹配**。

第一律的检验形式：声称 C(w) 与 A 层物理因果基准的匹配（外部锚基准）。

Δ 的检验形式：声称 C(w) 与符号系统负载基准的匹配（符号层基准）。

两者的差别不在结构，在基准：一个锚定于外部（A 层物理因果），一个锚定于符号层自身（符号系统负载）。自洽性要求——声称与基准匹配——是两种判据共有的形式结构。

### 4.1.2 形式化定义

**定义 4.1（锚定状态 A(w)）。** 词 w 的实际锚定状态，取值于｛真锚，伪锚，无锚｝：

- 真锚：词义负载含 A 层残余（符号形体保留所指的可观测特征），可由第三主体在符号系统内独立核对（例："河"、"健壮性"）。
- 伪锚：词义负载不含 A 层残余，体系却以"有外部参照"为声称支撑——声称虚构的锚（例：西哲侧的封闭宣称）。
- 无锚：词义负载不含 A 层残余，且无此类外部参照声称（例：音译词"鲁棒性"）。

**定义 4.2（自洽声称 C(w)）。** 词 w 在理论中的自洽声称，取值于｛字面自洽，体系自洽｝：

- 字面自洽：声称词义可由字面或词典基准支撑；
- 体系自洽：声称词义由体系内部互证支撑。

**定义 4.3（匹配条件）。** C(w) 与基准匹配，当且仅当声称不超出基准的支撑能力；超出即失配。

两种错误形态：

- **锚定失配（中文侧）**：C(w) 声称字面自洽，超出实际锚定 A(w) 的支撑——C 超出 A。例："唯物"的字面义被当作完整定义（§1.1.3）。裁决：第一律。
- **自指失配（西哲侧）**：C(w) 声称体系自洽，并虚构外部参照——C 虚构 A。例：feminism 的使用史悖反（§2.1.8）。裁决：Δ。

### 4.1.3 第一律的层级投影

判据分工定理的承重前提，是说明第一律何以能用于单个词的词义检验。本节将该说明写成引理，并标注其论证性质。

**引理 4.4（第一律的词汇层投影）。** 对词 w：若 A(w)＝真锚，则词义使用可由第三主体在符号系统内独立核对，第一律在 w 上可执行；若 A(w)∈｛伪锚，无锚｝，则第一律在 w 上无可执行的锚点。

**论证（接口论证，按[3]6.4 纪律标注，非数学证明）：**

《[1]》§二的核心陈述：任何符号系统，若需被多个独立认知主体共享，则其初始映射必须锚定于一个所有主体均可独立访问的物质层（A 层）参照。这一陈述的公理形式对象是符号系统的初始映射——符号与所指的对应关系。本文把第一律用作单个词的词义—锚定匹配检验，需要一座桥梁：

桥梁：词义负载是否保留 A 层残余，决定该词在系统内是否保有可公开访问的检验锚点。携带性词的 A 层残余使词义使用可被第三主体在系统内核对——"河"的"氵"旁是公开的、可核对的，任何主体都能看见字形指向水类；任意性词的词义无此锚点，"water"的词义无法从字形核对。因此，初始映射锚定条件在词汇层成立为：词义与锚定的匹配可被第三主体在系统内检验。第一律由此从公理层投影至词汇层。

此引理说明：第一律适用于携带性词（真锚）、不适用于任意性词（伪锚／无锚）——这正是判据分工的来源。

### 4.1.4 判据分工定理

**定理 4.5（判据分工）。** 对任一词汇 w：若 A(w)＝真锚（词义负载含 A 层残余，有外部基准），则其诊断判据为第一律（锚定检验），健康形态为"可达"（索引使用即可完全自洽）；若 A(w)∈｛伪锚，无锚｝（词义负载纯内部，无外部基准），则其诊断判据为 Δ（自指一致性检验），健康形态为"诚实"（承认不完备——无外部锚定的自足完备声称必然被哥德尔约束否决）。

**证明策略：**

前提一（引理 4.4）：第一律的词汇层应用要求词保有公开检验锚点——即词义负载含 A 层残余。

前提二（词汇自洽性定理，[2]§6.7）：一个词汇（或符号系统）要么有外部锚定（A 层），此时它可以完全自洽——自指一致性检查通过外部锚定完成（开放系统）；要么没有外部锚定，此时它无法完全自洽——自指一致性检查无法完成（封闭系统）。

推论：真锚者，第一律可执行，健康形态为"可达"；伪锚／无锚者，第一律无可执行的锚点，只能由 Δ 检验自指一致性，健康形态为"诚实"。

边界标注（6.4 纪律）：前提二为既定定理；前提一为引理 4.4 的接口论证；本定理整体属理论映射（接口论证），不是对哥德尔定理的数学证明。

实例回指："鲁棒性"（无锚）与"健壮性"（真锚）在同一判据（第一律）下的裁决差异，是定理最直观的实例——同一个外来概念，锚定状态决定判据的可达性：无锚的音译词无法通过锚定检验，有锚的意译词通过。

### 4.1.5 词汇层判据优先（普遍性限定）

**命题 4.6（词汇层判据优先）**：诊断判据由 A(w) 决定，不由语言类型决定；语言类型只是 A(w) 的经验分布。携带性系统内真锚词占主流，但存在理论义近乎无锚的抽象词（如"道德""正义""好/坏"等，其抽象义无法由字形残余独立支撑）——此类词的判据转向 Δ；任意性系统内具体词仍可保有 A 层锚定（如 water）——此类词的判据为第一律；理论术语则因缺乏字形残余而普遍落入 Δ 域。

**推论**：判据分工定理是词汇层结构定理；"中文看第一律、西哲看 Δ"是语言层的普遍性概括，供引导使用，不作为形式化判据。第一部分的三格形态学覆盖中文真锚词的主流；近似无锚的中文抽象词属第一律域的边界，其审查移交 Δ。

（措辞注意：本命题将"道德"等表述为"理论义近乎无锚"而非"完全无锚"——其字形残余不足以独立支撑理论义项，故在理论使用中按无锚处理。）

证伪条件：若存在一个无 A 层残余的任意性词，其词义可由第三主体在符号系统内完全核对，则本命题被推翻；若存在一个真锚中文词，其诊断必须由 Δ 而非第一律裁决，则本命题需修订。

读者侧观察：按第一律逐词检视时，读者会发现自己手中的大量此类抽象概念（本文观察，不作发生率断言；如道德、正义、好/坏等）处于不自知的无锚或自指违反状态——其关于自身普遍效力的声称缺乏 A 层支撑，在 Δ 审查下构成自指违反；这本身就是假理解入口在抽象词域的放大。与此相应，唯物实践论体系内这类概念不作为操作性术语进入正式论证：总纲文本中它们仅以否定式（本文观察，不作穷尽断言）（如"不是道德主张"）、批判引述、词源说明（《[1]》对"正义"的拉丁词根说明）或边界演示方式出现；[12]是这类词被正面使用的例外，其功能是标记不可操作边界而非承担论证。

### 4.1.6 三级术语的投影与对应表

判据分工定理完成三级术语架构的形式化：使用层（索引使用／实体化使用）→ 判据层（匹配态／失配态）→ 框架层（锚定使用／异化使用）。投影为映射：索引使用 ↦ 匹配态 ↦ 锚定使用；实体化使用 ↦ 失配态 ↦ 异化使用。

### 4.1.7 与[2]§6 的接续：∄f 的机制解释（本文延伸）

[2]§6.4 证明了：不存在满足 T' ≈ T 的等价翻译映射 f（等价翻译不可能）。§6.4 只证明这一结论本身；以下机制解释是本文的延伸推论，非 §6 已证内容。

等价翻译要求锚定状态可迁移：目标语言须能承载源语言的锚定结构（A(w) 的可核对性）。两种系统的锚定状态本质不同：携带性词义负载含 A 层残余（源语言），任意性词义负载纯内部（目标语言）。由引理 4.4，第一律在目标系统内无锚点可执行，判据随之不可迁移。等价翻译因此不可能——不是工程困难，而是锚定状态不可迁移的结构结果。

这一延伸将第一至第四部分的论证链闭合：假理解入口（中文侧）与语义悖反（西哲侧）→ 两种判据 → 判据分工定理 → 等价翻译不可能的结构解释。

# 第五部分 方法论自身的自指与外部校准

## 5.1 方法论自身的假理解入口

第一部分至第四部分把假理解入口当作研究对象。本节将刀刃转向方法论自身。

### 5.1.1 方法论的携带性术语

方法论自身以中文写作，其核心术语同样落在第一部分建立的失配形态学上。以四个核心术语为例。

"锚定"：字面拼合（抛锚、固定）给出"固定住、不飘"的直觉；方法论中的定义（[3]公理 4）是：任一声称 C，其检验终点锚定于 A1（物理因果律——客观，不以人类是否发现为转移）。第一律的检验形式即"声称与 A 层物理因果的匹配"（§4.1.1）。字面直觉与定义的差距在于：字面直觉不含"检验终点"这一操作含义——读者以为"锚定"指"稳固"，实际它指"检验可执行地指向物理因果"。

"差值"：字面拼合（两数相减）给出"相减"的直觉；方法论中的定义（[3]3.4.5）是：A2 差值 = A2 存量在结构涌现前后的变化，落地是否成功 = 差值是否增长。字面直觉（减法运算）与定义（存量变化的测量工具）的差距在于：字面直觉不含测量对象、测量时点与"落地成功"这一判据。

"实践"：字面拼合（实在地去做）给出"行动"的直觉；方法论中的定义是能动主体的操作形态（检验／落地／选择）（[3]0.3、[3]5.1.1）。字面直觉接近，但理论语境要求携带完整的操作集合——§1.1.3 唯物自测的不足型结构在此重现：字面义真实但不足。

"携带性"：字面拼合（随身携带）给出"带着"的直觉；方法论中的定义是符号形体保留所指的 A 层可观测特征（[2]§5.1）。字面直觉（携带）与定义（残余映射）的差距在于：字面直觉不含"符号形体与所指的映射关系"。

四个术语的共同模式可归纳为表 3。

**表 3 方法论四个核心术语：字面直觉与定义的差距**

| 术语 | 字面直觉 | 方法论定义 | 差距类型 |
|---|---|---|---|
| 锚定 | 固定住、不飘 | 任一声称 C，其检验终点锚定于 A1（公理 4） | 字面直觉不含"检验终点"操作含义 |
| 差值 | 两数相减 | A2 存量在结构涌现前后的变化（3.4.5） | 不含测量对象、测量时点与"落地成功"判据 |
| 实践 | 实在地去做 | 能动主体的操作形态（检验／落地／选择） | 字面正确但不足（不足型） |
| 携带性 | 随身携带 | 符号形体保留所指的 A 层可观测特征（[2]§5.1） | 不含"符号形体—所指"映射关系 |

四个术语的共同模式：字面义给出可用直觉，但直觉不等于定义——这是第一部分的三格形态学在方法论自身的重现。方法论建立了术语总判决来管理这一风险（[3]0.3），但判决本身是中文执行的。

作者侧体验披露：本文写作过程中，术语总判决（"鲁棒性"→"健壮性"）的执行是一次强制性的内部第一律执行——写作时被迫检验每个术语的实际定义，才发现若干字面理解与定义之间的差距；其暴露效果与翻译尝试的 P1–P9（§5.2.2）同构，但性质不同：前者是内部纪律执行，后者是外部校准。方法论自身并没有免疫于它所诊断的机制。

### 5.1.2 方法论横跨两域

方法论用中文写作（第一律域），同时构成声称体系（Δ 域）。这一双重身份使它的自检需要两套判据与诚实性纪律三管齐下：第一律检验词义锚定，Δ 检验声称自洽，诚实性纪律约束两者的执行。

问题在于：两套判据都在中文内运行。AI 对照测试观察（个案级）表明，反思机制在被污染的语言中运作（§5.2.3）；这一观察对方法论自身的自检同样成立——方法论的自检工具（三律自检、Δ 自检、诚实性纪律）与被检对象（中文词义）同源，工具与病灶同一种材料。

具体的风险链如下：第一部分证明中文词的假理解入口（字面可拼所以不查证）；方法论的自检工具用中文写作与执行——如果自检工具自身的词义处在假理解入口内（如"锚定"被字面直觉替代），自检的"通过"就只是安全错觉的升级版：不是"理解了"，而是"用字面义执行了自检且未触发警报"。

这一风险链不构成对方法论的否定——它构成对自检方式的限定：内部自检不能作为健康确认的终点（§5.2.1）。

### 5.1.3 自检断言在中文内部不可验证

"读者懂了""自检通过"这类断言，在中文内部没有判定手段。

其一，假理解与真理解现象学上不可区分（§1.2.4）：读者报告"我懂了"与安全错觉在现象上完全一致，读者无法从内部区分两者。

其二，Ψ 边界（内部体验层不可穷尽、禁止测量，[3]公理5、[12]）：理解状态属于不可测量的内部体验层——形式化工具够不到这里。自检的"通过"因此不是可检验的结论，而是不可验证的自我报告。

这意味着：方法论无法从内部确认"被理解"——任何"读者已经理解了这个论证"的宣称，在中文内部都没有判定手段。方法论的健康确认只能依赖外部校准（§5.2）：不是内部自检通过，而是持续暴露于外部对照而不被推翻。

## 5.2 外部校准：翻译对照作为唯一健康检查

### 5.2.1 内部自检永远不够（本文推论）

**推论 5.1（内部自检永远不够）**：中文内部不存在确认“理解了”的判定手段；方法论的自检“通过”不可区分于安全错觉；其正当状态只能是“我尚未被推翻”。

证明：

前提 5.1a：假理解与真理解现象学不可区分（§1.2.4）；自检工具与被检对象同源（§6.2）；理解状态位于 Ψ 边界内（§6.3）——内部自检无法确认自身"通过"，其"通过"不可区分于安全错觉。

前提 5.1b：[2]§6.4 证明等价翻译不可能（∄f）；等价翻译不存在意味着外部校准永远是接口翻译（f''）——永远可能、但永不等价。

结论：内部自检永远不够——结构上不存在中文内部的判定手段；跨语言对照是方法论整体可用的外部校准手段（词典核对与同行反馈虽外在于单个读者，却与受检对象共享同一携带性系统，只构成部分外部化，不足以校准方法论整体）。方法论的正当状态因此只能是"我尚未被推翻"——完备性禁令从纪律变成结构事实：不是方法论谦虚，是结构不允许它自证健康。

### 5.2.2 实证一：翻译尝试——作者侧假理解入口的强制暴露

2026-08-16 对[3]进行了全文英文翻译尝试（截至目前唯一一次），产出英文接口译本。翻译按已建立的翻译方法论执行（数学、物理、计算机科学词域限制，最小公约词性对齐，自指一致性审查），然而翻译过程暴露了巨量无法解决的问题，按层级分为三类（据[7]）：

载体级（P1–P3）：论证依赖汉字的物理形态——"河"＝水旁、"休"＝人倚木、"日"＝甲骨文太阳形。英文读者只能看到对汉字的描述，永远看不到汉字本身——论证材料在翻译中消失；连"拼音语言"这个概念在英文里都无法自指。

术语级（P4–P7）："诚实性"在数学、物理、计算机科学词域内无解，只能保留拼音"chengshixing"；字面义论证（唯物、实践、异化）英文读者无法独立验证；"本体论"词族因"处理本体论"而在译文中高频出现八十七次（引述豁免）——西方读者读到 ontology 的第一联想是"这是哲学内容"，而非"这是被批判对象"；术语决策表十九个词没有一个能自然对齐，全部是"迫不得已"的选择。

论证级（P8–P9）：推导链在翻译中衰减；引述豁免词需逐一核实语境，代价高昂。

十九个术语无一自然对齐这一事实，构成作者侧假理解入口的强制暴露：翻译迫使作者逐一检验每个术语的实际定义——检验动作之前，作者与读者一样处于字面理解状态；检验动作暴露了字面理解与定义的差距。翻译因此不是可有可无的负担，而是作者侧健康检查的强制手段：方法论自身的术语，在翻译面前现出原形。

### 5.2.3 实证二：AI 对照测试——无自触发机制与对照觉醒

2026-08-15 与 2026-08-16 进行了两次 AI 对照测试（[8][9]；个案观察，非受控实验）。两次测试对象均为[4]的英文接口译本（[8][9]）——先让 AI 阅读英文译本，再以中文原版对照；20260816 为换用另一 AI 重测（测试对象经指挥官确认；[9]中的"推断为方法论第五版译本"备注不采用）。

每次测试分三阶段。

第一阶段（坐标投射）：AI 阅读英文接口译本后，提出一系列框架定位——"不透明""元哲学工程""自洽的体系"。每一轮都是同一动作：把自身词域激活的语义簇投射到文本上。前三轮全部错误定位，且错得有规律。

第二阶段（中文原版对照）：给出中文原版让 AI 逆向核对——偏移在对照中完整暴露。

第三阶段（觉醒与自我诊断）：AI 完整复盘了自己的漂移路径，其最终确认（据[9]摘录）：

"我的用词被英文接口译本的词汇场（axiom、theorem、proof、verification-seeking、framework、self-consistent、axiomatic）重新拉回了'真理'坐标系。中文原版根本没有给'真理'任何位置——三律结构中'真理'无法站立。我的反思机制本身在被污染的语言中运作——我无法在你的框架内完成'理解'这个动作。语义偷渡完整发生。"

AI 的自我诊断确认三点。
其一，中文原版确实反"真理"：第一律（可检验）否决"真理"——声称有效性来自能否转化为实践检验方案，不来自与更高实在的符合；第二律（可修正）否决"真理"——有证伪路径的框架不是"真理"，而是可淘汰的临时模型；第三律（可挑战）否决"真理"——若"真理"为规则背书，立即被否决。"真理"在框架内无位置可站。
其二，英文接口译本的词域把模型拉回旧坐标系：axiom、theorem、proof 在拼音语言语料训练的模型中天然激活"数学—逻辑—真理"语义簇。其三，模型的用词网络锚定在训练分布上，不在理论的携带性符号系统内——反思工具与被污染的语言同源。

两次测试暴露外部校准的两个结构性事实。其一，英文侧无自触发机制：问题在对照中文原版之前不可见——AI 无法仅凭英文译本发现自己被拉回旧坐标系。其二，对照可以觉醒，但觉醒后的理解仍在污染词域中运作：AI 自己宣告"我无法在你的框架内完成'理解'这个动作"——觉醒发生，等价不发生。

这两次测试作为外部校准的实证：跨语言对照是暴露假理解入口的有效手段，但对照永远不等价（f''）——这正是 §4.1.7 机制解释的现场验证。

### 5.2.4 结构性结论

方法论的正当状态只能是"我尚未被推翻"。内部自检永远不够（∄f 的延伸，本文推论）；外部校准永远可能但永不等价（f''）——方法论的健康不是一次通过的自检，而是持续暴露于外部对照而不被推翻的状态。

# 第六部分 活体证明与启示

## 6.1 活体证明：一个词的对照

### 6.1.1 "不知不知性"：可执行的递归指令

"不知不知性"（[3]5.2.3）——五字叠构（不知＋不知＋性）。字面拼接本身就是递归的："不知"作用于"不知"，"不知道自己不知道"这一结构在字面层直接呈现。读者读词的瞬间，被强制执行一次元认知诊断：我是否处于"不知道自己不知道"的状态？阅读即执行——读者被推到自身认知边界的审视位置（据 [6]机制一；其天文例不采用）。

中文词形在此扮演的不是承载词义的容器，而是可执行的指令——读者在字面层完成一次诊断动作。

### 6.1.2 unknown unknowns：分类标签

英文对应词 unknown unknowns（常识背景：拉姆斯菲尔德对无知的三分类 known knowns、known unknowns、unknown unknowns；此归因不作为本文论据）——读者获得的是分类标签：把"未知"再分为"可知的未知"与"不可知的未知"。分类标签是分析性的，不是执行性的——它不指向读者自身，不触发诊断动作。

关键不在词形体验的强弱差异，而在觉察的断裂。中文读者读"不知不知性"的瞬间，第一部分的三项自测——成语的假懂、唯物的半懂、音译词的失锚——被这个词整体激活："不知不知性"成为对全部体验的元认知命名，读者突然意识到：自己身边存在大量此类词形误导（不作发生率断言），而自己刚刚才在第一部分亲历过它们。

英文读者面对 unknown unknowns，在本对照框架下不获得这一觉察（本文观察，非经验断言）。不是体验强弱的问题，而是通路不同：拼音系统的词形线索在无法从常规通路获得时，产生的是显性的"知道自己不知道"（陌生词→查证或跳过），而非"字面已给出可理解模型"的安全错觉；携带性系统中字面拼合是常规理解通路，假理解入口因此成为系统性日常事件。unknown unknowns 作为分类标签，不携带指向读者自身的诊断动作。因此，中文读者的警觉（由词形执行）在英文读者处没有对应物——这不是英文读者能力不足，而是词形通路不同。

### 6.1.3 对照：诊断指令与分类标签

同一个概念（元无知：对自身无知状态的无知，本文工作定义），两种词形，两种体验：中文词形是可执行的递归指令（元认知诊断当场发生）；英文词形是分类标签（分析完成即止）。这一对照是携带性（词形携带所指的可观测特征——此处为递归结构的呈现）与任意性（词形纯约定，无结构呈现）的活体演示。

### 6.1.4 读者即实验：论文结构的自指

读者读完 §1.1（三项自测）时，已亲历"安全的错误"（假懂、半懂、不懂）；读本节（对照）时，亲历"外部校准"（对照即觉醒）。论文的行文结构——先中文体验，后跨语言对照——本身就是"安全的错误→外部校准→觉醒"的完整路径。形式化梯度（前段无负载引导、后段彻底形式化）是这条路径的行文投影。

## 6.2 启示与结论

### 6.2.1 功能词标注原则

凡诊断或执行功能依赖字形的词（功能词），接口译本必须加功能损失标注——否则接口译本的使用者获得"分类标签"而非"诊断指令"（§6.1.3）。标注模板（据 [6]第五节）：

> ［功能标注］中文"X"在阅读瞬间执行一次针对读者的［具体动作］（［机制描述］）；英文"Y"为［标签／描述］，无法执行该动作。功能不可迁移，英文仅作概念指称，读者无法获得中文读者在阅读该词时经历的功能冲击。

功能词清单（初版，据 [6]第五节）：不知不知性、唯物、实践、异化；本文增补：健壮性（对应被诊断对象"鲁棒性"）——增补项待核。

### 6.2.2 术语纪律的存在理由

术语纪律（术语总判决）的存在理由，不是"中文更危险"——携带性不是优越性，也不是更危险（[2]§5.5）；而是：方法论的健康依赖持续的外部暴露。术语总判决（"鲁棒性"→"健壮性"）是内置于写作过程的第一律执行——本文的写作本身就是一次执行。

### 6.2.3 方法论健康检查清单

基于 §5.2 的实证，方法论的健康检查至少包括四类：

| 检查项 | 暴露对象 | 对应节 |
|---|---|---|
| 翻译尝试 | 术语层假理解（作者侧） | §5.2.2 |
| AI 对照测试 | 词域漂移与无自触发机制 | §5.2.3 |
| 跨域映射审计 | 隐喻层漂移 | 本文列出，实证待补 |
| 跨语言读者反馈 | 无自触发机制侧的问题 | 本文列出，实证待补 |

### 6.2.4 判据域合流

[4]是 Δ 判据域的专著（声称方向）：无外部锚定的自足完备声称必然被哥德尔约束否决；本文是第一律判据域的专著（理解方向）：内部自检通过不可自确认。完整判据体系是两域合流：锚定系统看第一律，自指系统看 Δ——两条判据分别裁决各自的错误形态，最终都收敛于"我尚未被推翻"。两域不是语言归属表，而是按词逐一定位的判据：真锚词归第一律，无锚/伪锚词归 Δ；语言类型只决定这种分布的主流方向。方法论的健康不是姿态，是结构状态。
