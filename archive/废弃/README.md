## 为什么不直接删

1. 本仓库对 GitHub 公开，删除会使已有外部引用 404；
2. 本仓库所在目录的 `.git` 所有权不属于当前账号，`git log` 不可读——**没有可回退的版本记录**。在无版本控制的前提下删除，是不可回收操作。

因此处理为：移入本目录 + 头部加废弃横幅 + 在根 `README.md` 与 `PUBLICATION.md` 中声明。

> 若需物理删除，由库所有者执行：`Remove-Item ".\_deprecated" -Recurse`。删除前请先确认外部无引用。

## 判断一个文件是否该进这里

两条，满足任一即应移入：

- **谱系分叉**：文件内的表述在正典（`core/唯物实践论：纪律与公理 第六版.md`）中找不到对应节，或与正典冲突；
- **无仲裁重份**：同一内容存在两个版本，且没有任何一方标明"以此为准"。
