## 这批案例是什么

它们是**演示品**，不是理论文献：用同一个框架跑五个具体场景，看结论是否站得住。

英文版的存在有一个特殊意义：按 `core/自指一致性声明.md`，**理论的等价翻译不可能**；但这些案例的英文版是**分析结果**的英文，不是理论的英文——那件事是允许的，也正是该声明为英文读者指出的唯一路径。

> 用法建议：先读 `core/` 的第六版，再看 case-3 或 case-4——这两篇的推导链最完整。
