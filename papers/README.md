# 衍生论文 · Derivative Papers

本目录收录基于唯物实践论框架的分析论文。这些论文是在框架不同发展阶段写作的，每个文件使用的框架版本有差异，阅读时请注意区分。

> **重要说明：** 这些论文是**应用分析**，不是理论核心文档。它们展示唯物实践论如何分析具体问题，但不代表理论本身的完整形态。核心理论请参见 `core/` 目录。

**关于版本标注：** 人民论写作于唯物实践论框架的早期阶段。当时框架尚未完成以下关键发展：

- **A1/A2 子类拆分**：A 层尚未分出 A1（物理）和 A2（价值）
- **第二律（认知自反剃刀）**：框架的自我证伪机制尚未建立
- **第三律（规则自讼剃刀）**：规则的元审判维度尚未纳入

因此人民论的范畴分析不完全等同于当前框架的精度。它在"结构层面"使用的是五元分类而非 A-B-C 六子集框架。这是理解人民论时必须注意的前置条件。
