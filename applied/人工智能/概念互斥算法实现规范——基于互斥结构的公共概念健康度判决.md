## 〇、文档定位

本规范定义"概念互斥算法"（变体对抗结构分析）的可执行实现：输入一个概念与它的变体来源（文献或语料），输出一张概念有效性判决卡。本规范将算法拆为**LLM 提取层**（可变、可消融）与**确定性内核**（不可变、可复现）两层，全部判决在确定性内核完成。

**设计铁律：**
1. LLM 是提取器，不是判决器——判决全部是确定性计算；
2. 锚定金标准是客观事实（可公共验证的检验接口），不是人类标注共识；
3. 每一个中间量可审计（可回溯到原文证据）；
4. A 锚判定是二元判定（是否携带可公共验证的预测），不是断言类型的细分分类。

## 一、算法总览

```
输入：概念 C + 变体源 S（学说史文献 / 公众语料）
│
├─ LLM 提取层（可消融）
│   ① 命题提取：核心可检验命题集 P = {p₁..p_k}
│   ② 变体枚举+极性聚类：V = {v₁..v_N}，polarity ∈ {赞成,反对,条件}
│   ③ A 锚判定：is_anchored(v) ∈ {True, False}（二元）
│   ④ θ_j 相位提取：每变体对共享观测事件的预测方向
│   ⑤ 矛盾判定：互斥对 (v_i, v_j, 共享事件 e, 预测冲突)（结构化规则）
│
├─ 确定性内核（可复现）
│   ⑥ 互斥图构建：G(V, E)
│   ⑦ 结构特征：N、M、μ、r、r_d、A_rate、Δν
│   ⑧ 判决函数 D(C) → {无锚假收敛, 可裁决争议, 健康} + 明细
│   ⑨ 判决卡输出（JSON，全中间量）
│
└─ 外部核验层（审计，非标注）
     每个 A 锚变体的"检验接口"（如碳十四/财报字段）→ 核验接口真实存在且可操作
```

## 三、LLM 提取层规范

### 3.1 命题提取（对应现有实现：qq_mutex_audit_v4.py 步骤 1）

- 输入：概念名 + 语料样本（或文献段落）
- 输出：1-3 个核心可检验命题
- 要求：命题必须"可检验"（可给出可观测预测）——非可检验命题（纯身份/规范表述）不入 P，但记录到旁路字段（用于事后对比）

### 3.2 变体枚举 + 极性聚类（步骤 2）

- 输入：核心命题 p₁ + 全部立场（语料）或定义性表述（文献）
- 输出：3-8 个变体，polarity ∈ {赞成, 反对, 条件}
- 要求：每变体保留 merged 编号（可回溯原文）；每变体附 evidence 片段
- 版本备案：提示词为实验参数，调整即版本变更（纪律：分脚本备案）

### 3.3 A 锚判定（二元，非细分分类）

**判据（重写版 4.3 操作化）：** 变体 v 是 A 锚变体 ⟺ v 携带至少一个可公共验证的预测（该预测可被独立观测者确认或否定）。

判定流程：
1. LLM 判定"该变体是否携带可公共验证的预测"；
2. 若为是，提取 `event` + `prediction` + `anchor_interface`（检验接口：什么观测能确认/否定它）；
3. **接口真实性由外部核验层审计**（见第六章）——LLM 说"可检验"不算数，接口必须真实存在。

**边界（防止滑回断言类型细分陷阱）：**
- 本判定是二元的：携带可公共验证预测 = A 锚；不携带 = 非 A 锚。
- 不做"事实/归因/规范"三分类，不做规范子类细分。
- 归因类变体（"股价跌因宏观"）若携带可验证预测（可映射到具体观测指标）即为 A 锚，否则为非 A 锚——由检验接口的真实性裁决，不由文本形态裁决。

### 3.4 θ_j 相位提取（r 的落地）

- 对共享观测事件 e（多个变体指向同一事件），每变体给出预测方向：
  - 预测事件发生/成立 → θ = 0
  - 预测事件不发生/不成立 → θ = π
  - 条件性预测 → θ = π/2
  - 对 e 无预测的变体 → 不参与该 e 的 r 计算（或记 NaN，统计时排除）
- 相位映射由确定性规则完成（LLM 只输出 event/prediction 文本，映射是代码逻辑）——**映射不进 LLM，保证可复现**。

### 3.5 矛盾判定（结构化规则）

**规则：** 变体 v_i 与 v_j 互斥 ⟺ 存在共享事件 e（两变体均对 e 有预测）∧ pred_i(e) 与 pred_j(e) 为互斥结果（如：发生 vs 不发生；发生在 A vs 发生在 B）。

- 判定由确定性代码执行（比较 (event, prediction) 对）——**不进 LLM**；
- LLM 只负责提供 event/prediction 的规范化文本；
- 严格版（论文默认）：仅"互斥结果预测"连边（对应 qq_pseudo_strict.py 的严格判定）；
- 宽松版（敏感性分析用）：含"方向相反的归因"连边——两版都跑，报告判决差异。

## 四、确定性内核规范

### 4.1 结构特征计算

| 量 | 公式 | 说明 |
|---|---|---|
| N | \|V\| | 变体数 |
| M | \|E\| | 互斥边数（严格版） |
| μ | M / C(N,2) | 矛盾率 |
| r | \|Σ_j e^{iθ_j}\| / N | 相干度（Kuramoto 序参数；θ 来自 3.4） |
| r_d | \|\|Σ v_j^(d)\|\| / Σ\|\|v_j^(d)\|\| | 前 d 轴子空间收敛度（观测面设计见 4.2） |
| A_rate | N_anchored / N | 锚定率（判决主轴量） |
| Δν | N_非A / (N_A · K) | 自指检测噪声（K 半操作化，待校准；先报告 N_A/N_非A） |

### 4.2 观测维度设计（S8 落地）

观测面 = 变体向量的一组轴。**三轴设计（主判决）+ 二轴设计（S8 真实数据验证实验）**（指挥官 2026-08-12 确认）：
- 轴 1 立场轴：polarity 投影（赞成/反对/条件）
- 轴 2 事件轴：对共享事件的预测方向投影
- 轴 3 主题轴：变体主题聚类投影（LLM 提取，消融对象）

**主判决用三轴**（观测面足够——增益带宽 4.9：二维下假/真收敛 r 差仅 0.003 几乎不可分，三维下 0.173 可分）。

**二轴（立场+事件）不做主判决**，作为 S8 的真实数据验证实验：假收敛概念预期二轴 r 虚高、三轴崩塌（Δr = r₂ − r₃ 大）；真收敛概念 Δr ≈ 0。若真实语料复现此模式，即维度判据在真实数据上的直接验证（论文真实数据版 S8 图）。

### 4.3 判决函数 D(C)

```
D(C) 输入：N, M, r, Δr, A_rate, align
align（S9 方向判据，外部核验后计算）：
  = 有已知检验结果的 A 锚变体中，预测方向与事实结果一致的比例

判决规则（组合，非单判据）：
  if A_rate < p* (0.25) 且 r 高（≥0.6）且 align 低（<0.5）:
      → 无锚假收敛（S9 + S10 联合）
  elif A_rate < p* (0.25):
      → 无锚（讨论悬空/二值化风险）
  elif M ∈ [7, 20]:
      → 可裁决争议（S7 临界区间，互斥对全锚定可检验命题时强度更高）
  elif M > 20:
      → 互斥超临界（瘫痪风险）
  else:
      → 健康（亚临界 + 锚定率达标）
```

**阈值策略（模拟值先行，阈值本身成为论文验证对象，指挥官 2026-08-12 确认）：** 先用模拟标定值跑（保持"框架预测 → 数据验证"叙事），敏感性分析展示判决对阈值的稳定性；若真实数据判决分界线与模拟值一致（如 p*≈0.25），阈值即升级为框架的可检验预测；若敏感性显示判决翻转率高，如实报告（判据鲁棒性边界）。

阈值表（初版按模拟值执行，敏感性分析后校准）：

| 参数 | 初值 | 来源 | 校准状态 |
|---|---|---|---|
| p*（S10 锚定率临界） | 0.25 | 模拟 S10 | 模拟标定，敏感性分析后与数据对照（预测验证） |
| M 临界区间 [7,20] | [7,20] | 模拟 S7 | 模拟标定，敏感性分析 |
| r 高阈值 | 0.6 | 待定 | 待数据标定 |
| align 低阈值 | 0.5 | 待定 | 待数据标定 |

### 4.4 判决输出附加量（Δν 降为附加，指挥官 2026-08-12 确认）

Δν = N_非A/(N_A·K)（自指检测噪声地板）**不入主指标**——与 A_rate 同源冗余，且 K 未标定。判决卡 audit 字段报告 N_A/N_非A 原始值；Δν 待 K 标定后再提。

## 五、外部核验层（审计，非标注）

对每个被判 A 锚的变体：
1. 提取 `anchor_interface`（检验接口描述）；
2. **核验接口的真实存在性**：该接口对应的观测手段/数据源是否真实存在（考古报告、财报字段、公开统计数据）——查证，不需要"判断什么是可检验"；
3. 对已有检验结果的接口，记录事实结果（用于 align 计算）；
4. 输出核验记录（每个接口的核验结论 + 依据）。

**与人工标注集的区别：** 人工标注集让标注员判断"这条评论是否锚定 A1"（需要框架知识，不可靠）；本层只查证"检验接口是否存在"（客观查证，可复核）。这是框架 4.3"不再依赖人工标注"的落地。
