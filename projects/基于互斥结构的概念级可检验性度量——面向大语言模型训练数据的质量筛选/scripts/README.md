# 可复现脚本（公开收录版）

本目录用于存放论文的可复现脚本。公开收录版已做去敏感性处理：

- 移除本地绝对路径（`C:\Users\...`、`E:\Users\...`）
- 移除 API Key 本地配置文件读取（改为环境变量或占位符）
- 保留 QQ 群真实名称，隐去群号
- 移除内部知识库路径引用
- API Key 一律改为环境变量/占位符，不读取本地配置文件
